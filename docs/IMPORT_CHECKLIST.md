# Pre-import checks for case-specific material

- [ ] Confirm GitHub visibility is **private**.
- [ ] Confirm every new file is a derivative with identifying data removed.
- [ ] Check names, aliases, case identifiers, addresses, phone numbers, account numbers, birth dates, signatures, and medical/school information.
- [ ] Check screenshots and PDFs for metadata, hidden OCR/text, comments, attachments, and embedded history.
- [ ] Check the text for indirect re-identification through combinations of dates, locality, benefits and family circumstances.
- [ ] Review commit messages, branch names, issue bodies, and filenames too.
- [ ] Mark draft letters as **not sent** unless receipt/transmission evidence is found.
- [ ] Keep untouched originals and original hashes in a separate secure vault.
- [ ] Review exactly what will be committed before upload.
